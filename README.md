# Artificial Intelligence Engineering Portfolio

**Author:** Fernando Avendaño Cabrera  
**Degree:** Artificial Intelligence Engineering — IPN (UPIIT)  

This repository compiles a selection of advanced projects developed within the field of Artificial Intelligence, Embedded Systems, and Optimization. The implementations focus on real-time processing, hardware integration, machine learning algorithms, and evolutionary computation. Rather than relying solely on high-level abstractions, these projects emphasize custom architecture design, physical sensor integration, and performance optimization.

---

## Featured Projects

### Project 1: Real-Time Medical Triage System

* **Category:** Embedded Systems | Real-Time Processing | Applied AI
* **Core Stack:** Python, Raspberry Pi 3, Hardware Sensors (Temperature, Load Cell/Weight, Ultrasonic/Height)

#### Overview
An automated health triage system designed for initial patient evaluation in hospital environments. The system interface reads biometric data in real-time through physical sensors connected to a Raspberry Pi 3, processes continuous data streams using Python algorithms, and outputs immediate status classification to streamline medical priority queues.

---

### Project 2: Hyperparameter Optimization using Genetic Algorithms

* **Category:** Evolutionary Computation | Machine Learning | Optimization
* **Core Stack:** Python, Scikit-Learn, Evolutionary Algorithms

#### Overview
Research and implementation focused on tuning Machine Learning model hyperparameters via Genetic Algorithms (GAs). This project explores custom chromosome encoding, selection mechanisms, crossover, and mutation strategies to traverse non-convex search spaces efficiently, beating standard grid or random search approaches. Presented at the *Tercera Semana de Ingenierías* (IPN UPIIT)[cite: 1].

### Project 3: Competitive Algorithmic Problem Solving

* **Category:** Algorithms | Data Structures | Optimization
* **Core Stack:** C++, Python, Competitive Programming Algorithms

#### Overview
A collection of efficient algorithmic solutions developed for competitive programming. Covers graph theory, dynamic programming, and greedy algorithms focused on minimizing time and space complexity under real-time execution constraints. *(Awarded 1st Place in the IPN Intermediate Programming Contest)*[cite: 1].
